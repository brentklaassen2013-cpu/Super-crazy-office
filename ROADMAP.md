# Build order after prototype 0.1

The game is deliberately being built in layers so movement/combat stay stable.

## 0.2 — VR movement polish
- Better body capsule collision
- Two-hand planted climbing
- Friction by surface
- Speed caps / anti-tracking-spike protection
- Comfort settings
- More accurate impact haptics

## 0.3 — Combat foundation
- Grabbable/equippable bats
- Bat stats + ability interface
- Better hit validation
- NPC hurt/KO states
- Proper sound/VFX hooks
- Lava Bat as first ability

## 0.4 — NPC foundation
- Coward / Fighter / Runner / Tank
- Reactions and voice-line state machine
- Clean / Mild / Strong language filter
- Nav behavior designed around vertical hand-locomotion maps

## 0.5 — Multiplayer
- Up to 4 players
- Solo / host / join
- 5-digit lobby codes
- Ready state
- Server-authoritative hit validation
- Player mute/report foundations
- WebRTC voice chat

## 0.6 — Progression
- Player XP / level choices
- Item XP / levels
- Rarity
- Coins / Gems
- Daily missions
- Inventory / collection

## 0.7 — Economy / trading
- Shop and bundles
- Non-pay-to-win stat rules
- Safe two-stage trading
- Countdown lock + final confirmation
- Trade history

## 0.8+ — Content systems
- Survival + bosses
- Many maps
- Random events / weather
- Horror maps / monsters / flashlight / jumpscares
- AI Director
- Seasonal events
- Achievements / leaderboards / minigames / PvP / hardcore / spectator / prestige

No crafting.
No separate secrets/mysteries progression.
No personal player-room system.
